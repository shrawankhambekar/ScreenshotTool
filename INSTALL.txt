============================================================
              WAYLAND SCREENSHOT TOOL - INSTALLATION
============================================================

>>> QUICK 1-STEP INSTALL (COPY & PASTE THIS COMMAND):
------------------------------------------------------------
unzip -o ScreenshotTool.zip && cd ScreenshotTool && ./install.sh
------------------------------------------------------------

Or if already unzipped inside this folder:
------------------------------------------------------------
./install.sh
------------------------------------------------------------

>>> OR ONE-CLICK GUI INSTALL:
Double-click "Install Screenshot Tool" (install.desktop) inside
your file manager.


>>> WHAT THE INSTALLER AUTOMATICALLY SETS UP:
1. Installs required system packages via apt, pacman, dnf, or zypper:
   - grim, slurp, wl-clipboard, wofi
   - GTK4 Layer Shell & Cairo Python bindings
2. Sets execution permissions on all scripts.
3. Creates system commands:
   - 'screenshot-tool' (interactive GTK4 overlay)
   - 'screenshot-menu' (Wofi toolbar menu)
4. Configures hardware keyboard shortcuts:
   - [Print Screen]       -> Interactive Screenshot Overlay
   - [Shift+Print Screen] -> Quick Toolbar Menu


>>> HOW TO USE AFTER INSTALLING:
- Simply press [Print Screen] on your keyboard.
- Or press [Shift] + [Print Screen] for the toolbar menu.
- Or run 'screenshot-tool' from any terminal.
Captured images are instantly copied to your clipboard ready
to paste (Ctrl+V) into chat, documents, or image editors!


>>> TO UNINSTALL:
./uninstall.sh
============================================================
