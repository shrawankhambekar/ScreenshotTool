============================================================
              CAPTUREPI - INSTALLATION GUIDE
============================================================

>>> QUICK 1-STEP INSTALL (COPY & PASTE THIS COMMAND):
------------------------------------------------------------
git clone https://github.com/shrawankhambekar/CapturePi.git CapturePi && cd CapturePi && ./install.sh
------------------------------------------------------------

Or if using a downloaded ZIP archive:
------------------------------------------------------------
unzip -o CapturePi.zip && cd CapturePi && ./install.sh
------------------------------------------------------------

Or if already inside this folder:
------------------------------------------------------------
./install.sh
------------------------------------------------------------

>>> OR ONE-CLICK GUI INSTALL:
Double-click "Install CapturePi" (install.desktop) inside
your file manager.


>>> WHAT THE INSTALLER AUTOMATICALLY SETS UP:
1. Installs required system packages via apt, pacman, dnf, or zypper:
   - grim, slurp, wl-clipboard, wf-recorder, wofi
   - GTK4 Layer Shell & Cairo Python bindings
2. Sets execution permissions on all scripts.
3. Installs app icon and desktop menu shortcut:
   - CapturePi in Application Menu under Graphics & Utilities
4. Creates system CLI commands:
   - 'capturepi' (interactive GTK4 overlay)
   - 'capturepi-recorder' (floating screen recording controller)
   - 'capturepi-menu' (quick toolbar menu)
5. Configures hardware keyboard shortcuts:
   - [Print Screen]       -> CapturePi Interactive Overlay
   - [Shift+Print Screen] -> CapturePi Quick Menu


>>> HOW TO USE AFTER INSTALLING:
- Simply press [Print Screen] on your keyboard.
- Or press [Shift] + [Print Screen] for the toolbar menu.
- Or run 'capturepi' from any terminal.
- Or launch CapturePi from your desktop applications menu.

Captured images are instantly copied to your clipboard ready
to paste (Ctrl+V) into Discord, browser, or documents!
Screen recordings are saved to ~/Videos/Recordings/rec_*.mp4.


>>> TO UNINSTALL:
./uninstall.sh
============================================================
